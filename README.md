# translate-os-static-demo

Static preview of the [TranslateOS](https://github.com/nabaraj-nobull/translate-os-static-demo) marketing site (exported from PHP templates in the main Bloom `build/` tree).

## Live site

After GitHub Pages is enabled: **https://nabaraj-nobull.github.io/translate-os-static-demo/**

## Regenerate (source project)

From the Bloom repo root:

```bash
php build/scripts/export-static.php
```

Then commit and push this folder again.

## GitHub Pages

**Settings → Pages → Deploy from branch `main` → folder `/ (root)`**
